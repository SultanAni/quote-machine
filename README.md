# 💬 Quote Machine

A tiny, dependency-free Python CLI that prints a random quote to brighten your day.

## Usage

```bash
python quote_machine.py
```

### Options

| Flag | Description |
|------|-------------|
| `-c`, `--category` | Pick a category: `inspiration`, `funny`, or `code` |
| `-n`, `--number` | How many quotes to print (default: 1) |

### Examples

```bash
python quote_machine.py -c code        # a random programming quote
python quote_machine.py -c funny -n 3  # three funny quotes
```

## Requirements

Just Python 3 — no external packages.
